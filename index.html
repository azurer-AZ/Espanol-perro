6️⃣ 语法要点 · 结构 + 用法 + 注意
语法点 结构 / 公式 用法说明 对话中的例句 注意事项
tener que + 原形 tener que + infinitivo 表示“必须做某事” Tienen que pasear al perro todos los días. 固定搭配
soler + 原形 soler + infinitivo 表示“通常做某事” La gente suele sacar al perro a pasear. 也可用 acostumbrar
para + 原形 para + infinitivo 主语相同，表目的 Salgo a medianoche para pasear al perro. 主语一致
para que + 虚拟式 para que + subjuntivo 主语不同，表目的 Salgo a medianoche para que el perro esté tranquilo. 必须虚拟式
a quien + 虚拟式 no hay nadie a quien + subjuntivo 否定先行词的定语从句 No hay nadie a quien le guste. 不看主语一致
se lo / se la se + lo/la + 动词 间接宾语 le/les + 直接宾语 lo/la → se lo/la Se lo devuelve. 不能说 le lo
aguardar vs esperar 两者都表“等待” aguardar 更书面，esperar 更口语且可表“希望” Aguardan a que vuelvan. esperar 可表“希望”
acostumbrar a + 原形 acostumbrar a + infinitivo 通常做某事 No acostumbra a poner correa. 也可用 soler
no se acostumbra a + 原形 无人称 通常不…… No se acostumbra a atar a los perros. 地区惯用
transcurrido + 时间 transcurrido + 时间，+ 主句 过了……之后 Transcurrido mucho tiempo, vuelve. 过去分词短语
antes de que + 虚拟式 antes de que + subjuntivo 在……之前 Antes de que vuelvan. 必须虚拟式
estar tumbado estar + tumbado 躺着（状态） Están tumbados sobre el cojín. 性数一致
de lado 固定短语 侧着 / 侧躺 Duermen de lado.
mucha gente + 单数动词 mucha gente + 动词单数 很多人（语法单数） Mucha gente sale... 不能说 mucha gente salen
los que más... ser los que más + 动词 最……的那些 Son los que más lo esperan. 强调结构
con gran curiosidad con + gran + 名词 带着极大的…… Exploran con gran curiosidad. gran 在名词前
soñar con + 原形/名词 soñar con + infinitivo/名词 梦见 / 梦想 Soñar con jugar al frisbee.
